# Marktyp 0.2.0-rc1

This release candidate previews the next Marktyp release and is intended for early testing before `0.2.0` becomes stable.

## Highlights

- A focused local-first workspace for creating, searching, renaming, and managing Markdown notes.
- Document, Source, and Dual editing modes with safer draft preservation and autosave behavior.
- Rich Markdown support for lists, task lists, tables, code blocks, images, Mermaid diagrams, and math.
- Reliable Markdown and rich-text paste, including native `Ctrl+V` and `Cmd+V` shortcuts.
- HTML and PDF export from the latest editor content.
- A new About dialog and opt-in GitHub release notifications with prerelease-channel support.
- Refreshed native application icons for macOS, Windows, and Linux.
- A reorganized Go and Svelte architecture with broader backend and browser regression coverage.

## What to test

- Creating, opening, renaming, switching, and deleting notes.
- Pasting Markdown in Document mode and moving between all three editing modes.
- Draft recovery, autosave, exports, lists, task lists, diagrams, and math rendering.
- Update notifications when moving from this RC to a later prerelease.

## Known limitations

- macOS and Windows packages are not notarized or signed by a trusted publisher yet, so the operating system may show a security warning on first launch.
- This is prerelease software. Keep a backup of important Markdown files and report unexpected behavior through [GitHub Issues](https://github.com/raml-dev/marktyp/issues).
